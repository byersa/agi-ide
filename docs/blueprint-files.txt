# SCREEN/COMPONENT: AgiWorkspace
# SUBTITLE: Where the IDE work is done

## 🛡️ CORE METADATA & RULE BOUNDARIES
* **Target Output Files:** 
  * Backend: `runtime/component/agi-ide/screen/agi-ide/AgiWorkspace.xml`
  * Frontend: None specified.
* **App Identity:** "Nursing Home Management System"
* **Security & HIPAA Enforcement:**
  * Sensitive Fields: None specified.
  * Audit Logging: False

## 📝 DESCRIPTION
This screen acts as the main orchestration area for agi-ide.
The standard display mode will be the multiple screen mode in which multiple AgiSubWorkspace screens will be visible. The replacement mode is an alternate mode in which one AgiSubWorkspace is expanded to occupy all of the AgiWorkspace content area.
The detached mode is when a AgiSubWorkspace screen is dragged from the AgiWorkspace area and dropped in another browser tab or in another browser all together.

It facilitates the communication and interactions of the AgiSubWorkspace screens.

### Subscreens
None specified.

### Subcomponents
- AgiSubWorkspace
- AgiCreateAppDialog

## 🛰️ INTER-COMPONENT BUS (BROADCASTCHANNEL)
* **Channel Name:** `agi-ide-context-bus`
* **Outbound Broadcast Events:**
  * Context Change: Broadcasts state change containing current artifact and subartifact identity to other active agent subworkspaces when a context switch is initiated.
* **Inbound Event Listeners:**
  * Context Change Listener: Receives notice from active agent subworkspaces, updates local stored context state (artifact and subartifact identity), and triggers synchronizations.

### Custom Specification Notes (Subworkspace notification)
Primarily used context switching. This screen maintains the identity of the current artifact and the subartifact.
When the context changes - as notified by one agent subworkspace, the change is stored and notice is sent to the other agent subworkspace.

## ⚙️ BEHAVIORS & BACKEND DATA CONTRACTS
* **Transitions / API Routes:** None specified.
* **Vue Internal Methods:**
  * App switching: When a request is made to load another app, a saved status check is done on the currently loaded app (if exists) and the user is prompted to save or cancel depending on the save status before loading the new app.
  * App creation: When a request is made to create a new app, a saved status check is done on the currently loaded app (if exists) and the user is prompted to save or cancel depending on the save status before popping up the AgiCreateAppDialog.
  * App deletion: None specified.
  * Subworkspace window management: The window display mode - multiple screen mode, replacement screen mode or detached window mode - will dynamically be controlled. When the user picks a mode, the screens will orient themselves to that mode. Depending on the user-selected mode, the corresponding subworkspace - primary or agent - will be displayed and made active.
  * `detachPanelToExternalWindow(panelName)`: Spawns a clean browser window popup (`window.open`), injects essential Quasar styling context headers, mounts the targeted component slice natively, and hooks it to the global `BroadcastChannel`.

## 🎨 VISUAL CONFIGURATION / WIDGETS
* **Declarative Layout Tree:**
  There will be a thin header section. It will have one dropdown to control the window display mode: multiple screen mode, replacement screen mode or detached window mode.
  There will be another dropdown that shows the available screens. The same dropdown will allow subcomponents to be deactivated or new ones to be added.

  The content pane can hold multiple AgiSubWorkspace windows.

## 📝 DESCRIPTION
This Vue component displays the rendered component and allows the user to perform the usual function associated with a visual screen editor. These would include selecting an element, positioning and sizing an element, adding an element from an AgiCanvasPalette, etc. 

### Subscreens
None specified.

### Subcomponents
* AgiCanvasPalette

## 🛰️ INTER-COMPONENT BUS (BROADCASTCHANNEL)
* **Channel Name:** `agi-ide-context-bus`
* **Outbound Broadcast Events:**
  * Element Status Change: Sends notice to the parent AgiSubWorkspace component when an element's status changes in the editor (which in turn communicates it to the AgiWorkspace grandparent component to be distributed to other AgiSubWorkspace components).
  * `canvas-element-selected`: Fired instantly when clicking any interactive form element row or layout primitive box. 
    * Payload Schema: `={ componentName: String, screenPath: String, elementId: String, elementType: String }`
* **Inbound Event Listeners:**
  * Element Status Change Listener: Receives notice forwarded via the parent when other AgiSubWorkspace components detect status changes from their child editor component, allowing this editor to update its contents accordingly.
  * `xml-source-mutated`: Receives payload `={ rawXmlText: String }`. Automatically triggers a 750ms debounced POST request to `/rest/s1/agi-ide/compileRawXmlToBlueprint` to dynamically refresh the visual layout widgets tree.

## 📥 INPUT PARAMETERS & PROPS
* **Moqui Screen Parameters:** None specified.
* **Vue Component Props:**
  * `Input artifact state`: Everything needed to manage an artifact
  * `editorMode` (String): Options: `'screen'` (default) or `'component'`. Dictates if the canvas should parse standard Moqui XML views via server sandboxing or handle raw Vue templates.
